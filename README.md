# Dinesh — Digital Universe Portfolio

A cinematic, production-grade portfolio engineered with **React 19**, **Vite**, **Material UI (MUI)**, **Framer Motion**, and **Supabase**. Built around a dark "universe" aesthetic, high-speed 60fps animations, WCAG AA accessibility, and real-time cloud database integration.

---

## 🚀 Tech Stack

* **Frontend Engine**: React 19, Vite 7
* **Design & Components**: Material UI (MUI v7), Emotion, Tailwind CSS
* **Animations & Physics**: Framer Motion 12
* **Database & BaaS**: Supabase (PostgreSQL, Row Level Security, PostgREST)
* **Code Quality**: ESLint 9 (Flat Config), Prettier-compatible conventions

---

## 🛠️ Getting Started

### 1. Prerequisites
* **Node.js**: v18.0.0 or higher
* **npm** or **pnpm**

### 2. Installation
```bash
git clone https://github.com/dinesh-dev1628/portfolio-app.git
cd portfolio-app
npm install
```

### 3. Environment Configuration
Copy `.env.example` to `.env` and supply your Supabase credentials:
```bash
cp .env.example .env
```

Ensure your `.env` contains:
```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

### 4. Running Locally
```bash
# Start development server
npm run dev

# Run ESLint validation
npm run lint

# Production build preview
npm run build
npm run preview
```

## 🗄️ Supabase Database Architecture & Schema

The application uses two primary public tables with public read-only Row Level Security (RLS) policies.

### 1. `projects` Table
```sql
CREATE TABLE IF NOT EXISTS public.projects (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  codename TEXT,
  sector TEXT,
  category TEXT NOT NULL,
  subtitle TEXT,
  description TEXT,
  problem_solved TEXT,
  technologies JSONB DEFAULT '[]'::jsonb,
  key_features JSONB DEFAULT '[]'::jsonb,
  github TEXT,
  demo TEXT,
  featured BOOLEAN DEFAULT false,
  status TEXT DEFAULT 'MISSION ACCOMPLISHED',
  in_development BOOLEAN DEFAULT false,
  coming_soon BOOLEAN DEFAULT false,
  accent TEXT DEFAULT '#38BDF8',
  glow TEXT DEFAULT 'rgba(56, 189, 248, 0.4)',
  stats JSONB DEFAULT '{}'::jsonb,
  display_order INT DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT now()
);
```

### 2. `experience` Table
```sql
CREATE TABLE IF NOT EXISTS public.experience (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  checkpoint TEXT NOT NULL,
  period TEXT NOT NULL,
  role TEXT NOT NULL,
  entity TEXT NOT NULL,
  status TEXT DEFAULT 'SYSTEMS OPERATIONAL',
  type TEXT,
  highlight TEXT,
  description TEXT,
  responsibilities JSONB DEFAULT '[]'::jsonb,
  technologies JSONB DEFAULT '[]'::jsonb,
  coordinate TEXT,
  accent TEXT DEFAULT '#8B5CF6',
  display_order INT DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT now()
);
```

### 3. Row Level Security (RLS) Policies
Ensure public anonymous visitors can query records while protecting write operations:
```sql
-- Enable RLS
ALTER TABLE public.projects ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.experience ENABLE ROW LEVEL SECURITY;

-- Read policies for anonymous clients
CREATE POLICY "Public read projects" ON public.projects
  FOR SELECT USING (true);

CREATE POLICY "Public read experience" ON public.experience
  FOR SELECT USING (true);
```

## 🌟 Key Features

1. **Supabase Real-Time Data Layer**: Asynchronous data hooks with graceful skeleton loaders, error telemetry banners, empty states, and schema normalization supporting both `snake_case` and `camelCase`.
2. **Cinematic Galaxy Preloader**: High-performance 3D canvas starfield accelerating from cruising speed into hyperspace streaks, galaxy burst, and smooth dissolution into the main site with skip options and reduced-motion support.
3. **Redesigned About Section**: Deep-space gradients, subtle nebula glows, floating star layers, and glass-morphism cards with WCAG AA compliant text contrast.
4. **Global UI Polish**: Dynamic scroll progress bar, back-to-top orbital return button, touch-friendly navigation drawer, and capped particle counts on mobile devices.
